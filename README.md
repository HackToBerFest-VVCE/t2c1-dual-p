# ShareWay AI

ShareWay AI is a registry-powered ride-sharing platform that matches passengers travelling along compatible routes.
It evaluates route compatibility, departure times, seat availability, and estimated costs to recommend suitable rides.
Specialized AI agents coordinate ride evaluations to provide explainable recommendations.
The project integrates the Solana Agent Registry to discover and evaluate registered agents using available identity, capability, and reputation information.
Our goal is to support efficient, transparent, and trust-aware mobility coordination.
